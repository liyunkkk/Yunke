# 消息指示器导航

单击沿箭头方向定位可见用户消息，不再按 Agent 逻辑轮次跳转。用户中途追加的补充消息也作为独立目标；系统自动续接消息仍隐藏，不新增目标。

- 向上：从回复或工具过程先回到其前面的最近用户消息；已经在该用户消息顶部时，再去上一条。长用户消息顶部已滚出时，先回到本条顶部。
- 向下：定位下一条用户消息；没有下一条时到底部。
- 长按仍按方向直达顶部/底部；方向判断、触觉、拖动取消动画和防连点保持不变。
- 使用折叠工作过程后的 timeline 索引，不使用原始消息索引，也不改变复制/最终结果按钮的轮次归属。
- 无障碍描述更新为“上一条用户消息 / 下一条用户消息”，英文、繁体中文同步。

本地独立 JVM 验证覆盖定位算法和生产 timeline 投影（轻量 UI 消息 DTO 替身），Compose 手势/动画测试仍需 Android CI。
